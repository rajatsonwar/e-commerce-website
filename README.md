# e-commerce-website

A modern and responsive eCommerce website designed to provide a seamless shopping experience. 
This platform allows users to browse products, add items to their cart, and securely complete purchases. 
It includes an intuitive admin panel for managing products, orders, and customer data, 
making it ideal for small to medium-sized online stores.

## Features

1 Browse product categories and search for items.
2 Add products to the shopping cart.
3 Order history and tracking.
4 Wishlist functionality for saving favorite products.
5 Responsive design for desktop and mobile devices.
